Эту папку необходимо скопировать в корень репозитория GitHub. Чтобы сайт отображал реальные изображения, загрузите медиафайлы с точными именами в соответствующие папки.

## 🌄 Фоновые изображения (`public/assets/backgrounds/`)

Загрузите фоновые файлы в формате JPG:
* `bg-abkhazia.jpg` — Пейзаж Абхазии (дорога, пляж, море)
* `bg-bedroom.jpg` — Уютная спальня Влада утром
* `bg-birthday-room.jpg` — Праздничная комната / гостиная с украшениями
* `bg-kitchen.jpg` — Кухня, где готовятся праздничные блюда
* `bg-waterfall.jpg` — Горы, водопад на заднем плане (сцена с предложением)
* `bg-alias-room.jpg` — Гостиная для игры в Alias
* `bg-ending-room.jpg` — Финальная праздничная сцена / комната
